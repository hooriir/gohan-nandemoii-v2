# 機能要件一覧仕様書 (gohan-nandemoii-v2)

本書は、`gohan-nandemoii-v2` における主要なユースケース、機能要件、および実装優先度（MoSCoW分析）を定義するドキュメントです。

---

## 1. 優先度定義 (MoSCoW)

* **Must (高)**: リリースに不可欠な必須機能（これがないとサービスとして成立しない）
* **Should (中)**: 重要な機能。代替案はあるが早期に実装したい機能
* **Want (低)**: あれば便利な機能・将来的な改善要求（優先度低）

## 4. 非機能要件（補足）

1. **セキュリティ**
   * 他の世帯のデータ（メニュー・履歴・メンバー情報）へはアクセスできないよう、リクエストごとに `household_id` による厳格な認可チェックを行う。
2. **レスポンシブ対応**
   * 日常生活（キッチンや買い物中）での利用を考慮し、モバイル端末（スマートフォン）に最適化したUIを提供する。
