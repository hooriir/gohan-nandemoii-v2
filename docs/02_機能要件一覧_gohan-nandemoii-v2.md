# 機能要件一覧仕様書 (gohan-nandemoii-v2)

本書は、`gohan-nandemoii-v2` における主要なユースケース、機能要件、および実装優先度（MoSCoW分析）を定義するドキュメントです。

---

## 1. 優先度定義 (MoSCoW)

- **Must (高)**: リリースに不可欠な必須機能（これがないとサービスとして成立しない）
- **Should (中)**: 重要な機能。代替案はあるが早期に実装したい機能
- **Want (低)**: あれば便利な機能・将来的な改善要求（優先度低）

## 4. 非機能要件（補足）

1. **セキュリティ・認可**
   - 他の世帯のデータ（メニュー・履歴・メンバー情報）へはアクセスできないよう、リクエストごとに `householdId` による厳格な認可チェックを行う。
2. **レスポンシブ対応**
   - 日常生活（キッチンや買い物中、移動中）での利用を前提とし、モバイル端末（スマートフォン）に最適化したUIを提供する。
   - **ブレークポイント**: Tailwind CSS の標準ブレークポイント（モバイルファースト配置。`md:` 768px 以上でデスクトップ用レイアウトに切替）を適用。
   - **検証想定端末**: スマートフォン（iOS Safari / Android Chrome、幅375px〜430pxクラス）およびタブレット・PC（幅768px〜1280px以上）。
