## サービス概要
**「今日のご飯、何がいい？」「なんでもいい〜」という毎日の悩み（メニューが決まらない問題）を解決するアプリです！**

世帯（家族）でメニューや履歴をリアルタイムに共有し、AI提案や被り防止機能を使って「我が家の定番」からサクッと今日のごはんを決定できます。

## なぜこのアプリを作ったのか（制作背景）
我が家では、「今日のご飯何がいい？」と聞くと毎回「なんでもいい」と言われてしまい、メニューが決まらないことが悩みでした。

メニューを提案してくれるアプリやAIは世の中にたくさんありますが、**「我が家の好みや食卓の定番に合わせたメニューの中から決めてほしい」**、そして**「家族みんなでメニューや食べた履歴を共有して相談できるようにしたい」** という思いから作成しました。

## 主な機能
- **ユーザー認証**: 新規登録 / ログイン・ログアウト / プロフィール変更 / パスワード再設定
- **世帯共有・家族招待**: 世帯作成・招待コード発行による家族メンバーの招待・世帯脱退・世帯単位でのデータ共有
- **メニュー管理**: ごはん（メニュー）の登録・一覧表示・編集・削除
- **スマート検索 & AI提案**:
  - キーワードによるメニュー検索・提案
  - **Gemini API** を活用した献立のアドバイスおよび家族の好みに合わせたAI調停機能
- **被り防止機能（履歴連携）**: 直近1週間に食べたごはん（メニュー）は検索結果から自動で除外

## こだわったポイント
- **家族間でのデータ共有と世帯管理**: 招待コード機能により、家族アカウント同士でメニューや食事履歴を簡単にシームレス共有できます。
- **直近履歴の自動除外**: 直近1週間に食べたメニューを自動判定して除外することで、「またこれ？」とならない検索ロジックを実装しました。
- **Gemini APIによるAIアドバイス**: 単なる機械的な除外だけでなく、家族の提案や好みに合わせたメニュー提案をAIが行います。
