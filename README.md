## サービス概要
**「今日のご飯、何がいい？」「なんでもいい〜」という毎日の悩み（メニューが決まらない問題）を解決するアプリです！**

キーワードを入力するだけで、登録されたお気に入りのメニューからアプリが今日のご飯を提案してくれます。

## なぜこのアプリを作ったのか（制作背景）
我が家では、「今日のご飯何がいい？」と聞くと毎回「なんでもいい」と言われてしまい、メニューが決まらないことが悩みでした。

メニューを提案してくれるアプリやAIは世の中にたくさんありますが、**「我が家の好みや食卓の定番に合わせたメニューの中から決めてほしい」** という思いがあり作成しました。

## 主な機能
- **ユーザー認証**: 新規登録 / ログイン・ログアウト / プロフィール変更 / パスワード再設定
- **メニュー管理**: ごはん（メニュー）登録・一覧表示
- **スマート検索**: キーワードによるメニュー検索・提案
- **被り防止機能（履歴連携）**: 直近1週間に食べたごはん（メニュー）は検索結果から自動で除外

## こだわったポイント
